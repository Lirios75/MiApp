# Respira

App de acompañamiento diario que ayuda a mujeres que gastan por ansiedad a sentir control de
su dinero, mediante un check-in emocional (el Semáforo del Gasto) y metas simples de ahorro,
sin conectar cuenta bancaria.

Construida con el Sistema Operativo para Web Apps con IA — ver `CLAUDE.md` / `AGENTS.md` y
`ESTADO.md` para el estado del proyecto.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
